## Ciclo de vida en React:
- Montarse → Renderizarse
- Actualizarse (montarse → renderizarse de nuevo)
- Desmontarse

[Lectura para saber más](https://reactiveprogramming.io/blog/es/react/ciclo-de-vida-de-los-componentes)

## Funciones relativas al ciclo de vida de un componente
- constructor: Se ejecuta al crear el componente.
- componentDidMount: Se ejecuta cuando el componente se monta en el DOM.
- componentDidUpdate: Se ejecuta cuando el estado cambia.
- componentWillUnmount: Se ejecuta antes de desmontar el componente.
